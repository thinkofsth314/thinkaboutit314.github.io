## 背包问题
* * n个物体，每个物体有体积和价值。在背包容量下装下最多价值的物体
### 01背包
* 每件物品只用一次

<img width="570" height="520" alt="6f18f88a699b113d99329bed5dc34fae" src="https://github.com/user-attachments/assets/6fe5ff59-53ac-4bcd-9e48-096f87300193" />



* 变量：物体，体积
* 集合：所有的选法


* 定义f(i,j):只从前i个物体里选，总体积不超过j的选法的最大价值。


* 选择条件：只从前i个物体选，总体积<=j
* 集合的划分：对于每个i物体，分成两个集合：只从1~i-1中选，和包含i的选法集合。


* 方法：集合划分后，就只有这两种情况了。分别分析两种情况取最大值。
  - 不含i：f(i-1,j)
  - 含i:先把所有i去掉，就变成了f(i-1,j-vi)，再加回来i的价值→f(i-1,j-vi)+wi


* 则最终答案：max{f(i-1,j),f(i-1,j-vi)+wi}

``` cpp
cin>>n>>m;
int v[n],w[n];
int f[n][n];

for(int i=1;i<n;i++)cin>>v[i]>>w[i];
for(int i=1;i<=n;i++){
  for(int j=0;j<n;j++){
    f[i][j]=f[i-1][j];//如果右侧没有元素，就直接等于左侧的
    if(j>=v[i])f[i][j]=max(f[i][j],f[i-1]j-v[i]+w[i]);
  }
}
```
