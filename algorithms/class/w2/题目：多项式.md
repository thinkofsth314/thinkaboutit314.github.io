## 思路
### 表示多项式
- 每一项：**一个结构体，存储系数和幂次，默认为0**
  - ``` cpp
    struct Term {
    int coef; // 系数
    int exp;  // 指数
    
    Term() {
        coef = 0;
        exp = 0;
    }
    
    Term(int c, int e) {
        coef = c;
        exp = e;
    }
    };
    ```
- 一个结构体数组，存储所有项
- **插入新项：自动升序排列，放在private里**
  - ``` cpp
    // 插入新项并保持按指数升序，自动合并同类项
    void addTerm(int c, int e) {
        if (c == 0) return; // 忽略系数为0的项
        int len = terms.getLength();
        for (int i = 0; i < len; ++i) {
            Term current = terms.getEleAtPos(i);
            
            if (current.exp == e) {
                // 指数相同，合并同类项
                current.coef += c;
                if (current.coef == 0) {
                    // 如果系数抵消为0，则删除该项
                    terms.deleteEleAtPos(i);
                } else {
                    // 否则更新该项的值
                    terms.setEleAtPos(i, current);
                }
                return;
            } 
            else if (current.exp > e) {
                // 2. 找到第一个指数大于 e 的位置，在此处插入，保证升序
                terms.insertEleAtPos(i, Term(c, e));
                return;
            }
        }
        
        // 3. 如果已有项的指数都比 e 小，则追加到顺序表末尾
        terms.insertEleAtPos(len, Term(c, e));
    }
    ```
### 构造和析构
- 基本构造：默认为无
- 给定幂次和系数（输入两个数组，和两个数组的大小）
  - ``` cpp
    IntPolynomial(int * c, int * d, int n){
         for (int i = 0; i < n; ++i)addTerm(c[i], d[i]);
    }
    ```
- 析构：空（terms 是对象成员，C++ 会在执行完外层类的析构函数体后自动调用它的析构函数，所以无需手动调用，外层析构函数体可以为空。）
