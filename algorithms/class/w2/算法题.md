- 暴力 O(n^2)
- 优化的算法
  - 思路:两个指针从左侧出发，根据差的大小向右移动。

  - 伪代码
  - ```text
    初始化：i = 0，j = 1
    
    当 i < m 且 j < m 时：
        如果 i == j：
            j += 1
            继续下一轮
    
        d = a[j] - a[i]
    
        如果 d < n：
            j += 1
        否则如果 d > n：
            i += 1
        否则：
            输出 a[i]、a[j]
            i += 1
            j += 1
    ```
### 复杂度
- 时间：O(m)
- 空间：O(1)
- ``` cpp

        }

        else{last++;}
    }
     
  }
