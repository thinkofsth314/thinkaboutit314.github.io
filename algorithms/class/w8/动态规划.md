# 动态规划

## 1. 基本思想

**把大问题拆成小问题，保存小问题的答案，再利用这些答案计算大问题的答案，避免重复计算。**

思考动态规划时，主要回答三个问题：

1. **状态是什么？** 要记录什么答案？
2. **状态转移是什么？** 当前答案怎样由更小问题的答案得到？
3. **初始条件是什么？** 最简单的情况，答案是多少？

## eg1： 爬台阶

有 n 级台阶，每次只能走 1 级或 2 级，求走到第 n 级的走法数。

### 定义状态

设 dp[i] 表示走到第 i 级台阶的走法数。

### 状态转移

按照最后一步分类：

- 最后走 1 级：之前在第 i−1 级，有 dp[i−1] 种走法。
- 最后走 2 级：之前在第 i−2 级，有 dp[i−2] 种走法。

两类不重复，而且包含所有可能，所以：

$$
dp[i]=dp[i-1]+dp[i-2].
$$

### 初始条件

$$
dp[1]=1,\qquad dp[2]=2.
$$

### 从小到大计算

| 台阶数 i | 计算 | dp[i] |
|---|---|---:|
| 1 | 只能走 1 | 1 |
| 2 | 1+1 或 2 | 2 |
| 3 | dp[2]+dp[1] | 3 |
| 4 | dp[3]+dp[2] | 5 |
| 5 | dp[4]+dp[3] | 8 |

### C++ 代码

假设 n≥1，且结果不超过 int 的范围。

```cpp
#include <vector>
using namespace std;

int ways(int n) {
    if (n == 1) return 1;

    vector<int> dp(n + 1);
    dp[1] = 1;
    dp[2] = 2;

    for (int i = 3; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }

    return dp[n];
}
```



##  eg2：最长公共子序列（LCS）

给定两个字符串 A、B，求它们最长公共子序列的长度。

### 什么是子序列？

**可以跳过字符，但不能改变字符的先后顺序。**

例如：

- A = ABCD
- B = ACBD

ABD 是两者的公共子序列，ACD 也是。最长公共子序列长度为 3。



$$
a_{i_t}=b_{j_t}=c_t,\qquad 0\le t<k.
$$


### 定义状态


$$
dp[i][j]=\text{**A 的前 i 个字符与 B 的前 j 个字符的最长公共子序列长度**}.
$$


例如 A=ABCD、B=ACBD 时：

dp[3][2] 比较的是 ABC 和 AC，所以 dp[3][2]=2。

注意：i、j 表示字符个数。若字符串下标从 0 开始，两个前缀的末尾字符分别为 A[i−1]、B[j−1]。



### 状态转移



观察**两个前缀的最后一个字符**，分两种情况。


#### 情况一：末尾字符相同

例如 ABC 和 AC，末尾都是 C。

可以先求 AB 与 A 的最长公共子序列，再在后面加上共同的 C：

$$
dp[i][j]=dp[i-1][j-1]+1.
$$

为什么这样一定最优？

- 给较短前缀的最长公共子序列加上共同末尾字符，能得到长度 dp[i−1][j−1]+1。
- 反过来，任意非空公共子序列去掉最后一个字符后，都能放进这两个较短前缀，因此原长度不超过 dp[i−1][j−1]+1。

所以等号成立。



#### 情况二：末尾字符不同

例如 AB 和 AC，末尾分别为 B、C。

这两个末尾位置不可能同时被同一个公共子序列使用：如果都使用，它们都必须对应公共子序列的最后一个字符，但它们不同。

因此至少舍弃一个末尾位置，比较两种方案：

- 舍弃 A 的末尾：答案为 dp[i−1][j]。
- 舍弃 B 的末尾：答案为 dp[i][j−1]。

取较大值：

$$
dp[i][j]=\max\{dp[i-1][j],dp[i][j-1]\}.
$$

这里是在比较两种方案，并不是提前决定永远删掉哪个字符。




### 初始条件

只要有一个字符串为空，公共子序列长度就是 0：

$$
dp[0][j]=0,\qquad dp[i][0]=0.
$$




### 完整递推公式

$$
dp[i][j]=
\begin{cases}
0, & i=0\text{ 或 }j=0,\\
dp[i-1][j-1]+1, & i,j>0,\ A[i-1]=B[j-1],\\
\max\{dp[i-1][j],dp[i][j-1]\}, & i,j>0,\ A[i-1]\ne B[j-1].
\end{cases}
$$



### 填表例子

A=ABCD，B=ACBD：

| A 的前缀 ＼ B 的前缀 | 空 | A | AC | ACB | ACBD |
|---|---:|---:|---:|---:|---:|
| 空 | 0 | 0 | 0 | 0 | 0 |
| A | 0 | 1 | 1 | 1 | 1 |
| AB | 0 | 1 | 1 | 2 | 2 |
| ABC | 0 | 1 | 2 | 2 | 2 |
| ABCD | 0 | 1 | 2 | 2 | 3 |

从上到下、每行从左到右计算：

- 末尾字符相同：左上角的数加 1。
- 末尾字符不同：取上面与左边的较大值。

最终答案是右下角：

$$
dp[4][4]=3.
$$

每个格子都利用已经算好的小问题答案，这就是动态规划在这个问题中的具体体现。
