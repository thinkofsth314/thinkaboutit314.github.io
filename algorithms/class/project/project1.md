# 小项目1：3-SAT问题


## 一、解题思路

### 1. 问题分析与初步想法

本题要求给 n 个布尔变量赋值，使 m 个表达式同时为真。每个表达式由三个项通过逻辑“或”连接，每一项是一个变量或该变量的取反。以下将每个这样的表达式称为一个“子句”。

使用 1 表示真，0 表示假。例如：

    x₁ ∨ ¬x₂ ∨ ¬x₄

为真的条件等价于：

    x₁ + (1 − x₂) + (1 − x₄) ≥ 1

因此，检查一个子句时，只要发现其中一项为真，就能确定该子句已经满足。

最直接的方法是枚举全部 2ⁿ 种赋值，逐一检查每组赋值是否满足所有子句。由于每个子句只有三项，检查一组赋值需要 O(m) 时间，因此直接枚举的最坏时间复杂度为 O(m · 2ⁿ)。

不同子句可能包含相同的变量，所以不能逐个子句独立选择赋值。一个变量的选择可能同时满足某些子句，又使其他子句更难满足，需要从整体上进行搜索。

### 2. 利用部分赋值提前判断

直接枚举是在所有变量都赋值后才检查结果，但实际上，在部分变量已经赋值时，就可能得到有用的信息。

对于一个子句：

- 如果至少有一项为真，该子句已经满足；
- 如果所有项都为假，当前赋值产生冲突；
- 如果其他项均为假，只剩下一项尚未确定，则最后一项必须为真；
- 如果没有真项，且至少两项尚未确定，则暂时无法进一步判断。

因此，可以一边赋值，一边检查和推导。出现冲突时立即停止当前尝试，不再枚举该分支下剩余变量的取值。

### 3. 单子句传播：优先进行必然的推导

如果一个子句只剩下一项尚未确定，其他项均为假，那么这最后一项必须为真。这种推导称为单子句传播。[1]

例如：

    x₁ ∨ ¬x₂ ∨ x₃

已知 x₁ = 0、x₂ = 1，那么前两项都为假，因此必须令 x₃ = 1。

新确定的赋值还可能使其他子句只剩下一项尚未确定，从而产生连续的推导。因此，每次主动选择变量后，都反复进行单子句传播，直到无法继续推导，或者发生冲突。

这些赋值是当前条件下必须成立的结果，不需要分别尝试两个取值，可以减少主动搜索的次数。

### 4. 分支搜索：在无法推导时进行尝试

如果无法继续传播，而且仍有子句未满足，就选择一个尚未赋值的变量，尝试将其设为 0 或 1，再继续传播。

基本的回溯方法是：先搜索其中一个取值对应的分支；如果该分支失败，就撤销该次选择及其后续推导，再尝试另一个取值。

单子句传播与这种分支搜索结合，构成 DPLL 算法的核心框架。[1]

但单纯回溯可能在不同分支中重复遇到由同一原因导致的冲突。为了减少这种重复搜索，进一步引入冲突驱动子句学习，即 CDCL。

### 5. 冲突学习：从失败中推出新的约束

出现冲突后，不仅撤销当前赋值，还分析哪些选择共同导致了冲突，并将它们不能同时成立这一事实写成新的子句。[1]

例如，假设当前存在以下约束：

    ¬a ∨ b
    ¬c ∨ d
    ¬b ∨ ¬d

这里使用较短的子句说明推理过程；原始输入虽然每条有三项，但推导和学习过程中可以出现不同长度的子句。

如果选择 a = 1、c = 1，那么：

1. 第一条要求 b = 1；
2. 第二条要求 d = 1；
3. 第三条要求 b 和 d 不能同时为 1。

因此产生冲突，可以推出：

    a 和 c 不能同时为 1

也就是：

    ¬a ∨ ¬c

将这条新子句加入后，后续搜索就能更早避开同样的错误。例如，当 a = 1 时，可以直接推出 c = 0。

这种新加入的子句称为学习子句。它由已有约束推导而来，因此不会排除原问题的任何可行解。

### 6. 非顺序回溯：直接退回需要修改的位置

普通回溯通常先撤销最近的一次选择，但最近的选择不一定与当前冲突有关。

利用学习子句，可以找到真正需要撤销的选择，直接退回较早的位置，跳过与冲突无关的中间尝试。这称为非顺序回溯。[1]

本方案采用 First-UIP 冲突分析方式：沿着冲突的推导原因向前分析，直到学习子句中只剩一个来自当前决策层的项。

其中，每次主动选择一个变量的取值，就进入一个新的决策层；由这一选择连续推出的赋值属于同一层。

随后回退到学习子句中其他项所属决策层的最大值；如果没有其他项，则回到第 0 层。回退后，学习子句会要求剩下的一项为真，于是可以立即进行新的传播。

这一过程把“发现冲突、学习约束、调整选择、继续推导”连接起来。

### 7. 动态选择变量，优先处理经常参与冲突的变量

变量选择顺序会影响实际搜索量。

最初可以根据变量在原始子句中的出现次数选择变量。但出现频繁，不一定意味着它是当前搜索中的关键变量，因此进一步根据冲突情况动态调整优先级。

具体思路是：

- 提高参与冲突分析的变量的优先级；
- 逐渐减弱较早冲突的影响；
- 每次需要分支时，优先选择当前优先级较高的未赋值变量。

这样可以使搜索更关注近期反复导致冲突的变量。这属于 VSIDS 类变量选择策略。[1][2]

该策略只改变搜索顺序，不改变必须满足的约束，也不作为变量应该取 0 或 1 的逻辑依据。

### 8. 整体求解流程

综合上述思路，算法按照以下过程运行：

1. 读取所有子句，初始时所有变量均未赋值。
2. 反复进行单子句传播。
3. 如果发生冲突，则分析冲突、生成学习子句，并回退到相应决策层。
4. 利用学习子句继续传播，并更新变量的搜索优先级。
5. 如果没有冲突，但仍有子句未满足，则选择一个未赋值变量进行新的尝试。
6. 重复上述过程，直到所有子句均满足。
7. 如果仍有未赋值变量，将其任意补全，检查原始子句后输出答案。

所有子句都已满足时，每条子句中都已有确定为真的项，因此任意补全其他变量不会破坏这些子句。

### 9. 方法的正确性与效率说明

该方法不会遗漏可行解，原因如下：

- 单子句传播只执行当前赋值条件下必然成立的推导；
- 冲突表示当前部分赋值无法扩展为可行解，因此可以放弃；
- 学习子句是已有约束的逻辑结论，不会删除原问题的可行解；
- 回退时保留学习到的约束，并据此继续探索其他可能的赋值。

相比直接枚举，该方法通过传播减少主动选择，通过冲突提前排除不可行分支，再通过学习避免重复出现同类错误。

但这些改进不构成所有规定规模实例都能在 5 秒内求解的最坏时间保证。实际运行效率需要通过测试验证，不能仅凭变量数和子句数作出统一的运行时间承诺。
