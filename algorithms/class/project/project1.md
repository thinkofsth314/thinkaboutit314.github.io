# 小项目1：3-SAT问题


## 一、问题理解与初步思考

### 1. 问题描述

给定 n 个布尔变量和 m 个表达式，每个表达式包含三个通过逻辑“或”连接的项。每一项可以是某个变量，也可以是该变量的取反。

目标是找到一组变量赋值，使全部 m 个表达式同时为真。题目保证存在解，因此只需要输出其中一组可行解。

使用 1 表示 true，0 表示 false。输入中的整数绝对值表示变量编号，正负号表示是否取反。例如：

- `2` 表示 x₂；
- `-2` 表示 ¬x₂，即 x₂ 的取反。

负号不表示这个变量已经被赋值为 false。例如，当 x₂ = 0 时，¬x₂ 的值反而是 1。

### 2. 将逻辑条件理解为求和条件

一个“或”表达式为真，当且仅当其中至少有一项为真。

例如，输入：

    1 -2 -4

表示：

    x₁ ∨ ¬x₂ ∨ ¬x₄

因为每个变量的取值只能是 0 或 1，所以 ¬x₂ 的值可以写成 1 − x₂。上述表达式为真的条件等价于：

    x₁ + (1 − x₂) + (1 − x₄) ≥ 1

因此，在检查一个表达式时，只要发现一项为真，就可以停止检查这一条表达式。

这里相加的是各项的真假值，而不是输入中表示变量编号的整数。

### 3. 暴力算法：枚举所有赋值

每个变量都有 0 和 1 两种取值，因此 n 个变量一共有 2ⁿ 种完整赋值。

最直接的算法是：

1. 生成一组完整赋值；
2. 检查全部 m 个表达式；
3. 如果全部为真，就输出该赋值；
4. 否则继续尝试下一组赋值。

每个表达式只有三项，检查一个表达式需要常数时间，检查全部表达式需要 O(m) 时间。

因此，直接枚举的最坏时间复杂度为：

    O(m · 2ⁿ)

提前停止检查可以减少实际计算量，但不会改变这一最坏时间复杂度。变量数较大时，直接枚举不可行。

### 4. 表达式无法独立求解

只看一个表达式时，让它为真并不困难：使其中任意一项为真即可。

但不同表达式可能包含同一个变量，因此它们的赋值必须保持一致。

例如：

    x₁ ∨ x₂ ∨ x₃
    ¬x₁ ∨ x₄ ∨ x₅

如果第一条通过令 x₁ = 1 得到满足，第二条中的 ¬x₁ 就会变成 0，需要由其他项保证第二条成立。

因此不能独立地看一个表达式，也不能独立地看一部分的表达式。

### 5. 从完整枚举转向部分赋值

不一定要等全部变量赋值以后，才能判断当前选择是否有问题。

在部分变量已经赋值的情况下，一个表达式可能出现以下状态：

| 当前状态 | 可以得到的结论 |
| --- | --- |
| 至少有一项为真 | 当前表达式已经满足 |
| 三项全部为假 | 当前赋值已经产生冲突 |
| 两项为假，剩下一项尚未确定 | 剩下的一项必须为真 |
| 没有真项，且至少两项尚未确定 | 暂时无法确定，需要继续赋值 |

这说明，可以在赋值过程中不断检查和推导，发现冲突后立即停止当前尝试，而不必补齐所有变量。

程序内部需要区分三种变量状态：

- 尚未赋值；
- 已赋值为 0；
- 已赋值为 1。

“尚未赋值”不能直接当成 0，否则可能错误地判断表达式已经为假。

### 6. 初步的变量选择想法

一想法是优先处理出现次数较多的变量，因为它可能同时影响多个表达式。

但需要区分两个问题：

1. 优先选择哪个变量？
2. 这个变量先尝试 0，还是先尝试 1？

由于表达式只要出现了1就可以直接短路判对，我的初步想法是将出现次数最多的变量直接赋成1。

但这种方法本身不能保证找到正确赋值，也不保证搜索次数一定减少。

### 7. 下一步需要解决的问题

在上述思考基础上，需要进一步设计：

1. 如何根据已有赋值，推出其他变量必须取什么值？
2. 无法继续推导时，如何选择变量进行尝试？
3. 出现冲突后，如何撤销错误的尝试并继续搜索？

下一部分将先讨论第一个问题。
