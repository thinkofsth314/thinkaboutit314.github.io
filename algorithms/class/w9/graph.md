# 图
## 图的逻辑结构
* 定义：图由**顶点的有穷非空集合和顶点之间的边集**组成，通常表示为**G=(V,E)**
  - V表示点集，E表示边集
  - 图的顶点个数不能为0，但是可以没有边

### 基本概念
* 无向边：(vi,vj).无向图：任意两个顶点之间的边都为无向边
* 有向边：<vi,vj>，表示**从vi到vj**
* 简单图：不存在顶点到自身的边，同一条边不重复出现
* 邻接
* 完全图
* 度，入度，出度
* 网：边上带权的图
* 路径
  - 路径长度：非带权图为边的个数，带权图为路径上各边的权之和
  - 简单路径：顶点不重复出现的路径
  - 回路
* 子图
* 连通图
  - 连通分量：非连通图的极大连通子图（连通的点和依附于这些顶点的边）
    - 连通分量是对无向图的一种划分
  - 强连通图：有向图里，若途中任意一对顶点vi,vj满足vi→vj和vj→vi均有路径

* 生成树：n个顶点的**无向连通图G**的生成树是包含G中**全部顶点**的**极小连通子图**
  - 极小连通子图：含有n-1条边。（多：构成回路；少：不连通）

  - 最小生成树：生成树里面权重和最小（不唯一）





### 不同逻辑关系的对比
- 线性：元素之间仅有线性关系，为前驱和后继
- 树：层次关系，有双亲和孩子
- 图：任两个顶点都可能有关系，邻接关系

- 握手定理
  - 无向图：度数和=边数*2
  - 有向图：出度和=入度和=边数

## 最小生成树

### MST性质
  - 若G(V,E)是一个无向连通网，U是顶点集V的一个非空子集，(u,v)是一条具有**最小权值**的边，u∈U,v∈V-U，则**必然存在一棵包含边(u,v)的最小生成树**
  - 
### prim算法
#### 思路
  - 先选定G中一个任意顶点A，此时U={A}.
  - 取与A邻接，且边的权值最小的点，设为B,将U扩为{A,B}，再看U连到V-U权值最小的边。设这条边是(B,C),则将U扩为{A,B,C}
  - 继续扩张，直到V-U为空。此时之前的流程选出来的边加上所有顶点就是最小生成树

#### 时间复杂度O(n*n)

### kruskal算法

#### 思路
- 初始化就让U=V，让最小生成树T的边集先为空（一开始T的连通分量就有n个，即n个独立的顶点）
- 在E中寻找最短边(u,v)，如果(u,v)位于T两个不同的连通分量，则将这条边加入T的边集，并把两个连通分量合并为一个连通分量。重复操作，直到T只剩下一个连通分量

#### 代码实现
- 存储边：使用三元数组
- 合并连通分量：使用一个parent数组，记录哪些顶点属于同一个连通分量
  - 初始化各个顶点parent[i]=-1
  - 合并连通分支时，假设是2和1合并到0，则p[2]=1,p[1]=0,p[0]=-1。称此时0为根。
  - 考察是否在同一个连通分支：找到两个顶点的根是否为同一个顶点
    

#### 复杂度：排序边最快是O(klogk),k为边数。找连通分量

## 最短路径算法
* 非网图中：两顶点边数最少的路径
* 在网图中，两顶点之间边权重和最小的路径

### 单源点最短路径问题：Dijkstra算法
* 固定顶点v，给定带权有向图G，求v到G其他顶点的最短路径

#### 算法思路
- 初始化S={v}
- 从v开始，将v到其他顶点的边的权重为其他顶点的值。没有直接连接的记为∞.
- 设值最小的顶点为k，则S更新为{v,k}，再看v→k→其他顶点的边,如果v→k→j小于v→j，就更新j的值为v→k→j
- 再次选择值最小的顶点i,S扩为{v,k,i}，继续更新值
- 重复这个过程，直到S=V。此时所有顶点对应的值为v到它的最小路径

#### 实现思路
- 存储：带权的邻接矩阵
- 数组dist[i]：表示从v到vi的最短路径长度，每次循环会更新
- path[i]:表示这一次循环更新后vi到v的最短路径（可以只存储连接vi的最后一个顶点）
- s[i]：存放源点和已经生成的终点

### 每一对顶点之间的最短路径：floyd算法
* 给定带权有向图G，对任意顶点vi,vj，求vi到vj的最短路径
* 一个方法：每次以一个顶点调用dijkstra算法，时间复杂度为O(n^2)
