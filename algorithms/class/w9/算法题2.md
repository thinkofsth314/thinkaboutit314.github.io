## 1、强连通分量
<img width="700" height="622" alt="屏幕截图 2026-11-26 201637" src="https://github.com/user-attachments/assets/378957ac-01e7-4a27-94e8-6726c1d756ac" />

### 思路
- 直接暴力解。
- 考虑每个顶点出和入的两次DFS，这两个辅助函数只打上标记不输出
- 建立两个数组，如果都是true，则位于同一个强连通分量，且这个强连通分量不会有其它的顶点

### 代码
#### 辅助函数
``` cpp
void markOutDFS(int st,bool* visited){
  visited[st]=true;
  graphNode<T>* tmpNode = verList.getEleAtPos(st);
  for(int j=0;j<tmpNode->outs->getLength();j++){
      int target=verList.locateEle(tmpNode->outs->getEleAtPos(j));
      if(visited[target])continue;
      markOutDFS(target,visited);
  }
}
  
void markInDFS(int st,bool* visited){
  visited[st]=true;
  graphNode<T>* tmpNode = verList.getEleAtPos(st);
  for(int j=0;j<tmpNode->ins->getLength();j++){
      int target=verList.locateEle(tmpNode->ins->getEleAtPos(j));
      if(visited[target])continue;
      markInDFS(target,visited);
  }
}
```


#### 实现函数
``` cpp
void printStrongCC(){
  bool* print=new bool[numVer]();
  int comp=0;
  for(int i=0;i<numVer;i++){
      if(print[i])continue;

      bool* out=new bool[numVer]();
      bool* in=new bool[numVer]();
      markInDFS(i,in);
      markOutDFS(i,out);

      cout<<"Component "<<comp<<": ";

      for(int j=i;j<numVer;j++){
          if(out[j]&&in[j]){
              cout<<verList.getEleAtPos(j)->data<<" ";
              print[j]=true;
          }
      }

      cout<<endl;
      comp++;

      delete[] out;
      delete[] in;
  }

  delete[] print;
}
```

## 2、固定终点的最短路径
<img width="765" height="311" alt="屏幕截图 2026-11-26 201735" src="https://github.com/user-attachments/assets/962c143f-90e6-48d7-9846-8f3cf880f4de" />

### 思路：直接从Dijkstra算法里面修改以下的东西：
  - 从S连出去改为连到S里，dist还是一样选最小迭代，对应路径就存nextnode
  - 打印：已知每个顶点最短路径的下一个顶点。则不断把nextnode放入队列就可以让end在最后打出

### 代码实现
``` cpp
void distFromAllTo(T end){
  int dist[numVer];
  int nextNode[numVer];
  bool isInS[numVer];

  int sInd=verList.locateEle(end);

  //初始化
  for(int i=0;i<numVer;i++){
      dist[i]=-1;
      nextNode[i]=-1;
      if(adjMatrix[i][sInd]!=0){
          dist[i]=adjMatrix[i][sInd];
          nextNode[i]=sInd;
      }
      isInS[i]=false;
  }

  isInS[sInd]=true;
  dist[sInd]=0;
  nextNode[sInd]=-1;

  int numInS=1;

  while(numInS<numVer){
      int minInd=-1;
      int minDist=-1;

      for(int i=0;i<numVer;i++){
          if(dist[i]==-1)continue;
          if(isInS[i])continue;
          if(minDist==-1||dist[i]<minDist){
              minDist=dist[i];
              minInd=i;
          }
      }

      if(minInd==-1)break;

      isInS[minInd]=true;
      numInS++;

      //迭代
      for(int i=0;i<numVer;i++){
          if(isInS[i])continue;
          if(adjMatrix[i][minInd]==0)continue;
          int newDist=minDist+adjMatrix[i][minInd];
          if(dist[i]==-1||newDist<dist[i]){
              dist[i]=newDist;
              nextNode[i]=minInd;
          }
      }
  }

  //打印
  cout<<left<<setw(18)<<"Vertice name"<<"Path"<<endl;
  for(int i=0;i<numVer;i++){
      cout<<left<<setw(18)<<verList.getEleAtPos(i);
      if(dist[i]==-1)
      {   cout<<"Unreachable"<<endl;
          continue;
      }

      LinkQueue<int> s;
      int j=i;
      while(j!=-1){
          s.enQueue(j);
          j=nextNode[j];
      }

      bool first=true;
      while(!s.isEmpty()){
          if(first){
              cout<<verList.getEleAtPos(s.deQueue());
              first=false;
          }
          else{
              cout<<" -> "<<verList.getEleAtPos(s.deQueue());
          }
      }
      cout<<", cost = "<<dist[i]<<endl;
      
  }
}
```

## 3、无向连通网的切割边
<img width="742" height="344" alt="屏幕截图 2026-11-25 210828" src="https://github.com/user-attachments/assets/d4169b7b-be10-48ca-a6a4-2e91fa188fc2" />

### 思路：
  - **切割边一定在所有的连通树里**，则我们只需要通过prim/kruskal算法找到最小生成树，然后检查每条边
  - 检查每条边：对于e，写一个辅助函数，即跳过不看e的dfs，返回bool值。对e的两个顶点之一使用这个辅助函数
  - 上面的辅助函数应该对原图进行特殊dfs，而非找到的最小生成树。

### 代码实现
#### 辅助函数
``` cpp
// 从 current 出发，在原图中跳过边 (u, v)，看能否到达 v
bool canReachWithoutEdge(int current, int u, int v, bool* visited) {
    if (current == v) return true;
    visited[current] = true;

    for (int k = 0; k < numVer; k++) {
        if (adjMatrix[current][k] == 0) continue;
        if (visited[k]) continue;

        // 无向边的两个方向都要跳过
        if ((current == u && k == v) || (current == v && k == u))
            continue;

        if (canReachWithoutEdge(k, u, v, visited))
            return true;
    }
    return false;
}
```

#### public里的实现函数
``` cpp
AMGraph<T>* criticalEdge(){
  //先找到最小生成树，切割边一定在所有生成树里面
  AMGraph<T>* t = PrimMST();
  bool* visited = new bool[numVer];

  for (int u = 0; u < numVer; u++) {
      for (int v = u + 1; v < numVer; v++) {
          // 每条树边只检查一次
          if (t->adjMatrix[u][v] == 0) continue;

          for (int k = 0; k < numVer; k++)
              visited[k] = false;

          // 在原图中能绕过去，说明这条边不是桥，从 t 中删掉
          if (canReachWithoutEdge(u, u, v, visited)) {
              t->removeEdge(verList.getEleAtPos(u),verList.getEleAtPos(v));
          }
      }
  }

  delete[] visited;
  return t;

}
```
