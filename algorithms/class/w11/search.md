# search
## 概述
- 静态查找：只找，不进行其他操作
- 动态查找：可能有
- 查找结构：面向查找操作的数据结构，我们讨论**线性表，树，散列表**
  - 线性表：适用静态查找，顺序和二分
  - 树表：适用于动态查找，采用**二叉排序树**
  - 散列表

## 线性表

#### 暴力
直接遍历，时间复杂度O(n)

#### 优化


### 二分
- **必须先排序再查找，必须采用顺序存储**
- 时间复杂度最优的排序算法是O(nlogn)，一次二分是O(logn)
  - 查一次就是O(nlogn+logn)，并不优于顺序。
  - 如果查找m次，顺序为O(m*n),二分为O(nlogn+mlogn)就会优
